# Security Policy

This repository contains the YANTRA-001 Python contract foundation but has no supported release or production runtime. Do not send secrets or sensitive exploit payloads in public issues. Report suspected vulnerabilities privately to the repository maintainers through a contact channel they publish; no dedicated security contact is configured in this repository yet.

Future policy must define supported release branches, response expectations, disclosure coordination, and advisory process. Security design requirements are documented in [threat model](docs/security/threat-model.md). No certification or security guarantee is claimed.
