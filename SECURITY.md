# Security Policy

YANTRA `0.2.0` is an unreleased, pre-1.0 developer-preview candidate. The repository includes a model gateway, bounded agent runtime, tool authorization and trusted approval flow, and an optional restricted worker subprocess; it is not a production security product or OS sandbox. Do not send secrets or sensitive exploit payloads in public issues. Report suspected vulnerabilities privately to the repository maintainers through a contact channel they publish; no dedicated security contact is configured in this repository yet.

Future policy must define supported release branches, response expectations, disclosure coordination, and advisory process. Security design requirements are documented in [threat model](docs/security/threat-model.md). No certification or security guarantee is claimed.
