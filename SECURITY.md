# Security Policy

This repository currently contains documentation only; there is no runtime to secure or supported release. Do not send secrets or sensitive exploit payloads in public issues. Report suspected vulnerabilities privately to the repository maintainers through a contact channel they publish; no dedicated security contact is configured in this repository yet.

Future policy must define supported release branches, response expectations, disclosure coordination, and advisory process. Security design requirements are documented in [threat model](docs/security/threat-model.md). No certification or security guarantee is claimed.
