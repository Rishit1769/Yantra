# Contributing

YANTRA currently contains documentation only and has no established build or test commands. Start with [documentation index](docs/index.md), [contribution workflow](docs/development/contribution-workflow.md), and [coding standards](docs/development/coding-standards.md). For proposed code, include tests, public contract impacts, threat/retention considerations, and docs; do not claim behavior without verified evidence.

The project license and contribution terms are unresolved. This file does not grant rights or create a contributor license agreement. Maintainers must select and publish licensing/contribution policy before accepting code contributions for distribution.
