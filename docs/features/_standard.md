# Feature Specification Standard

Every feature specification includes Overview, Motivation, uniquely identified Functional requirements, Non-functional requirements (security, performance, reliability, scalability, maintainability), Architecture, Data flow, Interfaces, Persistence, Configuration, Security, Error handling, Observability, Testing, measurable Acceptance criteria, Dependencies, Priority (P0-P3), Implementation status, and Open questions.

Status vocabulary: Proposed, Specified, In Development, Implemented, Verified, Deprecated. YANTRA-001 contract foundations and the YANTRA-002 gateway foundation are implemented; broader feature systems remain Proposed or In Development as their documents specify. Gateway protocol tests use mocked transports, not live services. Acceptance criteria describe future completion unless the document cites verification evidence. IDs use `YANTRA-<AREA>-NNN` and must be unique repository-wide.
