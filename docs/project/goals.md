# Goals

1. Provide a typed, asynchronous, model-neutral runtime with explicit provider capabilities.
2. Offer a dependency-light core and optional infrastructure adapters.
3. Make every tool action subject to independent authorization and bounded execution.
4. Represent execution state and observations in versioned contracts suitable for inspection and recovery.
5. Provide durable sessions and checkpoints through a persistence interface without coupling Python to Prisma.
6. Treat skills as reusable, immutable-version content with declared permissions and controlled loading.
7. Support deterministic workflows alongside bounded model-driven agent loops.
8. Make evaluations reproducible and document limitations rather than infer quality from anecdotes.
9. Evolve public APIs compatibly where practical, with explicit deprecation policy.

All goals are proposed; acceptance is defined in [roadmap criteria](../roadmap/acceptance-criteria.md).
