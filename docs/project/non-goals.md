# Non-Goals

- Replacing or training foundation models.
- Owning application-specific business logic, repository workflows, or end-user product behavior.
- Depending on NIRMAAN, PROMETHEUS, or a single model/provider vendor.
- Requiring PostgreSQL, Redis, pgvector, browser automation, a GUI, or distributed workers for simple local use.
- Treating model output as trusted code, authorization, or policy.
- Guaranteeing exactly-once effects for arbitrary external systems.
- Circumventing access controls, CAPTCHAs, provider limits, or website policies.
- Claiming Docker alone isolates hostile workloads.
- Embedding LangChain, CrewAI, AutoGen, or LangGraph as the core orchestrator.
- Declaring production readiness based on feature completion without measurable operational and security evidence.
