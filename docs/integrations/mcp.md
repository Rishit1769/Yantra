# MCP Integration (Design)

MCP is an optional protocol adapter, not a core orchestration dependency. Remote servers are untrusted providers of schemas, resources, and tool results. Validate identity/transport/schema, apply YANTRA policy to every invocation, restrict network and credential scopes, and record server/version provenance. Supported protocol versions/transports remain open. See [MCP feature](../features/mcp-integration.md).
