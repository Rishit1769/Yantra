# Contribution Workflow

Before implementation, discuss public contract/security changes; use an issue or design note for substantial work; keep PRs focused; include tests, migration compatibility, documentation, threat/retention impact, and acceptance evidence. Never include secrets or user data. Reviewers check requirement traceability, backward compatibility, and status accuracy.

This workflow is proposed. Until governance and license are selected, contribution terms and rights are unresolved; do not imply a contributor license agreement or license grant.
