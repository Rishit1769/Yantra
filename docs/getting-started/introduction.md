# Introduction

YANTRA is currently a documentation-only architectural blueprint. There is no usable package, runtime, CLI, or supported installation. This section records the intended development experience without presenting it as available.

The initial user is a Python developer who needs a controlled model/tool loop and wants to choose providers. The core should run in process with an in-memory adapter; durability, browser automation, vector search, and distributed workers are opt-in subsystems.

Before a real quickstart is published, Phase 1 must deliver a versioned SDK, at least one tested provider adapter, a minimal tool policy path, documented installation from an actual artifact, and CI verification. See [milestones](../roadmap/milestones.md).
