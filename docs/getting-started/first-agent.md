# First Agent (Proposed)

The first implemented agent example should demonstrate a model-neutral definition, one read-only tool, finite step/time/token limits, an explicit permission policy, and structured result handling. It must use a mock provider in tests and clearly isolate any optional live-provider test. It should show how to inspect run IDs and events without requiring a database or inspector.

No runnable first-agent example exists yet. Its acceptance criteria are part of [Phase 1](../roadmap/milestones.md#phase-1-foundation).
