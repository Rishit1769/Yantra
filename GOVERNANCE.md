# Governance

YANTRA is licensed under the Apache License, Version 2.0; see [LICENSE](LICENSE). No formal governance model or maintainer decision process is established in this repository. This document records that gap rather than inventing authority. Before releases, maintainers should publish roles, decision-making and escalation process, security response ownership, roadmap/API-change approval, and conflict-of-interest expectations.

The license does not establish project governance or a separate contribution agreement.
